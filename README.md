# Script-to-Video AI

An AI-powered system that converts a user-provided script into a complete generated video.

## Workflow

Script

→ AI Scene Planning

→ Video Prompt Generation

→ Voiceover Generation

→ AI Video Generation

→ Video Composition

→ Final MP4

## Planned Technology

- Python 3.12
- FastAPI
- AWS SDK / boto3
- Amazon Bedrock
- Amazon Polly
- Amazon S3
- FFmpeg
- React / Vite

## Development Phases

1. Project foundation
2. AWS / Bedrock connection
3. Script-to-scenes generation
4. Voiceover generation
5. Single video scene generation
6. Multi-scene orchestration
7. FFmpeg composition
8. End-to-end API
9. Frontend
10. QA and submission
