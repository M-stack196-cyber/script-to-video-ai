# Script-to-Video AI

## Goal

The user provides a script, and the intended complete workflow is:

```text
Script
  → AI scene planning
  → validated scene JSON
  → AI-generated video clips
  → AI-generated audio
  → FFmpeg composition
  → final MP4
```

## Selected Models

| Purpose | Selection | Model ID |
| --- | --- | --- |
| Primary text model | Claude Sonnet 4.6 | `us.anthropic.claude-sonnet-4-6` |
| Temporary CEO-approved text model | Amazon Nova Pro | `us.amazon.nova-pro-v1:0` |
| Video model | Amazon Nova Reel v1.1 | `amazon.nova-reel-v1:1` |
| Audio model | Amazon Nova Sonic | `amazon.nova-sonic-v1:0` |

## Implemented

- Python 3.12 backend and FastAPI application
- AWS Bedrock bearer API authentication and model discovery
- Text-model Converse API integration
- Pydantic `Scene` and `ScenePlan` validation
- Deterministic mock scene planner for quota-safe development and demos
- Amazon Nova Reel v1.1 asynchronous integration and job-status lookup
- Safe API configuration-status endpoint and API orchestration
- Automated tests
- FFmpeg installed on the development machine

Mock scene planning is explicitly a development/demo mode. It is used while AWS
text-inference quota is exhausted and never activates as an automatic fallback
after a real AWS failure.

## API Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/health` | Service health check |
| `GET` | `/api/config/status` | Safe configuration readiness flags |
| `POST` | `/api/video/plan` | Generate and validate a scene plan |
| `POST` | `/api/video/generate-scene` | Submit one Nova Reel scene asynchronously |
| `GET` | `/api/video/status` | Look up one Nova Reel job status |

Example scene-planning request:

```bash
curl -X POST http://127.0.0.1:8000/api/video/plan \
  -H 'Content-Type: application/json' \
  -d '{
    "script": "Turn everyday moments into a story worth sharing.",
    "duration": 12,
    "aspect_ratio": "9:16"
  }'
```

## Current External Blockers

1. AWS currently returns `ThrottlingException: Too many tokens per day` when
   invoking Claude Sonnet 4.6 and Amazon Nova Pro.
2. Real Nova Reel generation requires an approved S3 bucket and the required AWS
   permissions.
3. Nova Sonic audio integration is not complete and requires its supported
   bidirectional streaming and authentication setup.
4. FFmpeg final composition and the frontend remain upcoming phases.

No final AI video is claimed to have been generated by this MVP.

## Setup

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Environment Variables

Create local environment configuration using placeholders only. Never commit real
credentials.

```dotenv
AWS_REGION=us-east-1
AWS_BEARER_TOKEN_BEDROCK=
BEDROCK_TEXT_MODEL_ID=us.amazon.nova-pro-v1:0
BEDROCK_VIDEO_MODEL_ID=amazon.nova-reel-v1:1
BEDROCK_AUDIO_MODEL_ID=amazon.nova-sonic-v1:0
USE_MOCK_SCENE_PLANNER=false
S3_BUCKET_NAME=
```

## Demo

From `backend/`, start the quota-safe demo API with:

```bash
USE_MOCK_SCENE_PLANNER=true uvicorn app.main:app --reload
```

## Tests

Run from `backend/` with the virtual environment active:

```bash
python -m compileall -q app tests
USE_MOCK_SCENE_PLANNER=true python tests/test_scene_generator.py
S3_BUCKET_NAME= python tests/test_video_generator.py
USE_MOCK_SCENE_PLANNER=true python tests/test_api.py
```

The empty `S3_BUCKET_NAME` in the video-generator command ensures that it exits
without submitting a paid Nova Reel generation.
